One original English sentence, phrased as a clause that could sit buried
deep inside a terms-of-service agreement: deadpan legal boilerplate that
quietly turns absurd. Built for the [make.fun](https://make.fun) bounty
[The Absurd Clause Contest](https://make.fun/c/u-donrulezz-the-absurd-clause-contest-035cc0f1).

## The clause

> By using this service, you agree to lend us your left shoe on alternate
> Tuesdays and to accept its return, if any, in a different size.

## Run

```sh
python3 main.py
```

The program is fully deterministic — no network, no randomness, no input
files. It writes the single clause above to `/output/entry.txt`
(135 characters, one line, no trailing newline).
